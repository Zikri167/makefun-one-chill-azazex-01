One sentence of horror for the "One Line, One Chill" bounty: a sleeper wakes to his own voice whispering his name from the hallway outside his bedroom, and the scare is not the voice itself but how patient it sounds — as if whatever is wearing it has been waiting all night, and can wait longer.

## Run it

```sh
node main.ts
```

This writes the single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
